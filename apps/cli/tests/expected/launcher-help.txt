Usage: nhs [--profile] <name> [options] [app-args...]
       nhs plugin --profile <name> <pnpm-args...>

nhs: boot a NoHarness profile — an ordered stack of plugin-bundle patch
layers under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 nhs --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $NHS_HOME/profiles to boot
  --from-default-profile <name>  replace a custom profile with a fresh copy of a
                                 shipped profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  nhs web                                   boot the web profile (same as: nhs --profile web)
  nhs rescue --from-default-profile web
                                            recreate rescue from the shipped web template, then boot it
  nhs headless "run the tests"              answer one task, print the result, and exit
  nhs tui --patch ./extra.yml               boot a custom profile with one extra overlay
  nhs tui --resume <session>                arguments after the launcher flags reach the app
  nhs web --help                            the web app's own flags and help
  nhs plugin --profile tui add <package>    install a plugin into the tui profile
